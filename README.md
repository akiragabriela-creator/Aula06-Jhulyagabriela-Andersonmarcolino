# Atividade - Aula 06: Python (Squad UrbanInventory)

## Descrição da Tarefa
Resolução dos exercícios práticos utilizando funções em Python (`all()`, `any()` e *list comprehensions*) para monitoramento de equipamentos hospitalares.

## Tarefas Realizadas
1. **Verificação de Prazo (`all()`):** Checa se todos os equipamentos estão dentro do limite de dias.
2. **Alerta da UTI (`any()`):** Identifica se há equipamentos na UTI com pendência de revisão.
3. **Filtro de Problemas (*List Comprehension*):** Extrai a lista de IDs dos equipamentos que necessitam de atenção.
